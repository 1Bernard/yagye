# Roadmap

**Last updated:** 2026-10-18

This directory documents features that are planned but not yet built.

## Contents

| Document | Description |
|---|---|
| [remaining-features.md](remaining-features.md) | Comprehensive catalog of every deferred or upcoming feature — what each one is, why it matters, its phase, prerequisites, and implementation approach |

## Reading order

Start with [remaining-features.md](remaining-features.md). Features are grouped
by readiness: unblocked work first, then near-term (P14–P16), then compliance
(P21), then platform analytics and core extensions.

The phase numbers in that document refer to the Yagye build plan. The
`// DEFERRED:` annotations in the DBML files (`docs/schema/`) are the
authoritative per-table source; this document adds the reasoning and
implementation guidance that the DBML cannot carry.
